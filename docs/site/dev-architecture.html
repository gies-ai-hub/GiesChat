Architecture

GiesChat is a fork of LibreChat: a Node/Express API and a React client in one npm-workspaces monorepo, with Gies features layered on top (about 280 commits past the upstream merge base). Remote upstream is danny-avila/LibreChat and is synced with merge commits, so keep Gies changes in their own files where you can.

Workspace map

FolderWhat lives there
client/The React app. src/routes (pages), src/components, src/hooks, and src/data-provider (React Query hooks).
api/The Express server, in JS. server/index.js mounts every route; then server/routes → controllers → services. strategies/ holds the passport login strategies. Increasingly a thin wrapper over packages/api.
packages/api/Backend logic in TypeScript, where new backend code should go: agents/, admin/ (class dashboard), embed/, rooms/, replit/, issues/, mcp/, stream/, app/ (config loading).
packages/data-provider/The client/server contract: endpoint URLs (api-endpoints.ts), data-service.ts, request and response types, and the librechat.yaml schema (config.ts).
packages/data-schemas/Mongoose schemas, models, DB methods and system capabilities. See Data model.
packages/client/Shared UI pieces and the theme provider.
config/Admin CLI scripts from upstream, plus Gies seed scripts: seed-gies-tutors.js, seed-app-builder.js, seed-career-prep.js.
infra/Separately deployed MCP servers: ms365-mcp/ (Outlook) and pptx-mcp/ (Python PowerPoint server).
e2e/Playwright end-to-end tests.
Build order matters: the client and API import the built output of packages/*. After pulling changes that touch a package, rebuild the packages (see the README) or you'll run stale code.

Where to put a new feature

  1. Types and the endpoint URL go in packages/data-provider.
  2. Schema changes go in packages/data-schemas.
  3. Logic goes in packages/api/src/<feature> as a handler factory that takes its DB functions as dependencies (see createAdminUsageHandlers).
  4. A thin route goes in api/server/routes, mounted in api/server/index.js.
  5. A React Query hook goes in client/src/data-provider, and the UI in client/src/components.

Gies fields on agent

In packages/data-schemas/src/schema/agent.ts:

FieldPurpose
courseFree-text class label used to group dashboard usage.
createdViaWhich surface built the agent. A UI filter hint, never an access check.
embed{ key, audience, greeting, theme }. key is the link credential and is never selected by default.
collaborators / pendingCollaboratorsUser ids allowed to draft, and invited emails waiting for a first sign-in.
coAdmins / pendingCoAdminsSame, for co-admins.
draftOf, draftBase, postedVersionSet on drafts: which production agent it copies, the production version it started from (used to detect "production has changed since"), and the version it became when posted.
support_contactWho students should contact.

On user: onboardingCompletedAt (tour) and embedAgentId (embed guests).

Other Gies collections

  • issueReport: reports from the bug button.
  • tutorSource: scraped course pages behind the course tutors.
  • room, roomParticipant, roomMessage, roomPoll: Brainstorm Rooms disabled in prod.

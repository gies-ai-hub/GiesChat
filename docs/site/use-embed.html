Embedding an agent

Put your class agent on a Canvas page or course site so students can chat without opening GiesChat.

1. Open the embed dialog

In the Agent dashboard, find your agent and choose Embed. Visitors chat with this agent inside your page. Each visitor gets private conversations and can only use this agent: no uploads, no other models.

2. Choose who can use it

  • Illinois accounts only: best for graded courses. Chats are tied to each student, so they show up in your per-student activity.
  • Anyone with the link: for public pages and outreach. Each visitor is an anonymous guest.

3. Paste it into Canvas

Choose Copy snippet. In a Canvas page, use Embed → HTML (or switch the editor to HTML) and paste it. Students see the chat inline, and a switch in the chat header lets them flip between a white and a black background.

Turning it off

Revoke link stops new visitors immediately. Tabs already open keep working until they reload. Embed traffic has its own rate limit, so a busy embed won't slow down GiesChat itself.

Building a class agent

A class agent is an assistant you set up for your students. You give it instructions, course documents and a model, and students chat with it. You build and monitor agents from the Agent dashboard.

Getting access

The Agent dashboard lives at /admin. If you see "You don't have access to the agent dashboard," ask a GiesChat administrator to give you access. Faculty get dashboard access individually.

1. Build an agent

In the Agent dashboard, choose Build an agent. Fill in:

  • Name and course: e.g. FIN 300 Office Hours, with course label FIN 300. The course label is shown on the agent in the dashboard.
  • Instructions: how the agent should behave. For example: "Guide students to the answer with questions. Never solve graded problem sets."
  • Documents: up to 50 files (syllabus, lecture notes, practice problems). The agent searches them to answer.
  • Websites: paste a page address (e.g. your course site) and choose Test to see exactly what would be read, then Add. GPT-6 Luna reads up to 50 pages from that site, under that address, and saves a clean copy the agent answers from. The copy is re-checked every night.
  • Model: which AI model students get. Students can't change it in chat.

2. Test models before you pick one

Not sure which model fits? Choose Test models in the builder. You ask two models the same sample questions using this agent's instructions and documents, and see their answers side by side. Nothing is saved to chats or class analytics.

3. Say who students should contact

Under Contact for students, choose Me, Someone else (a TA or course coordinator, e.g. Jordan Kim (TA)) or Not now. Students see this contact on the agent. With "Not now," they see you, the agent's author.

4. Share it with your class

Once it's saved, students can open the agent from the dashboard link you share, or you can embed it in Canvas. Use Open in chat to try it yourself as a student would.

Watching how it's used

The dashboard's Your agents table shows conversations and messages per agent, filtered by class and time window. Opening an agent shows per-student activity and a What students ask panel that groups recent questions into topics. Use it to spot what to revisit in lecture.

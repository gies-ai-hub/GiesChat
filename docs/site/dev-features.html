Gies features → code

Everything GiesChat adds on top of LibreChat, and the files that own it. Start here when a bug report names a feature.

Class dashboard (/admin)

Professors build agents, see usage per agent and per student, analytics, and "What students ask" topics.

  • UI: client/src/components/Admin/: Dashboard.tsx, AgentUsageTable.tsx, StudentProgressTable.tsx, Analytics/
  • API: api/server/routes/admin/usage.js (/api/admin/usage/*) → packages/api/src/admin/ usage.ts, analytics.ts, topics.ts

Collaborators, co-admins & invites

  • UI: client/src/components/Admin/Drafts/CollaboratorsDialog.tsx
  • Emails: api/server/services/AgentInvites.js, template api/server/utils/emails/inviteCollaborator.handlebars
  • Role → ACL mapping: api/server/services/AgentAccess.js. Invites are claimed at sign-in in api/strategies/openidStrategy.js.

Agent drafts

  • UI: client/src/components/Admin/Drafts/ DraftsPanel.tsx, PostDraftDialog.tsx
  • API: /api/admin/usage/agents/:id/drafts. Drafts copy documents through api/server/services/Files/copy.

Websites

  • UI: client/src/components/SidePanel/Agents/Websites.tsx, WebsitePreview.tsx (dashboard builders only, via showWebsites)
  • API: POST /api/admin/usage/websites/preview (Test) and POST /api/admin/usage/agents/:id/websites (Add/Refresh) → packages/api/src/sites/ (crawl.ts, extract.ts runs GPT-6 Luna, store.ts, refresh.ts re-checks nightly)
  • A saved site is one agent document with metadata.sourceUrl; api/server/services/Websites.js stores and swaps it.

Model test & model lock

  • client/src/components/SidePanel/Agents/ModelTest.tsx → POST /api/admin/usage/model-test → packages/api/src/admin/modelTest.ts
  • Dashboard-built agents lock the model in chat: client/src/hooks/Agents/useAgentModelLock.ts

Support contact

  • client/src/components/SidePanel/Agents/SupportContact.tsx, packages/api/src/agents/contact.ts

Embed

  • UI: client/src/components/Admin/EmbedDialog.tsx, routes /embed/:embedKey in client/src/routes/EmbedRoute.tsx
  • API: api/server/routes/embed.js → packages/api/src/embed/ session.ts, guard.ts; limiter api/server/middleware/limiters/embedLimiter.js

Report issue

  • client/src/components/Chat/ReportIssueDialog.tsx → /api/issues → packages/api/src/issues/ service.ts (diagnosis from recent logs), github.ts (files a GitHub issue via GITHUB_ISSUES_REPO / GITHUB_ISSUES_TOKEN)

Onboarding tour

  • client/src/components/Tour/ steps.ts, useOnboardingTour.ts; completion is saved via POST /api/user/tour/complete. The replay menu item is in client/src/components/UnifiedSidebar/More.tsx.

Course tutors, Career Prep, App Builder

  • Seeded agents: config/seed-gies-tutors.js (+ config/gies-tutors/ scraper), config/seed-career-prep.js, config/seed-app-builder.js
  • App Builder: Replit MCP block in librechat.yaml, api/server/routes/replit.js, packages/api/src/replit. The preview renders through packages/data-provider/src/externalUrl.ts.

Outlook & Deck Builder

  • Outlook: infra/ms365-mcp/. The students-only gate is in client/src/hooks/MCP/useMCPServerManager.ts.
  • Deck Builder: infra/pptx-mcp/, question card client/src/components/MCPUIResource/QuestionDock.tsx

Brainstorm Rooms / MindForum disabled in prod

Multi-user rooms with live chat, @ai mentions, polls and catch-up summaries. Behind interface.brainstormRooms, which is currently false.

  • client/src/components/Brainstorm/, api/server/routes/rooms.js, packages/api/src/rooms/, the room* collections
